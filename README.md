# 🛸 Rick and Morty App

Пет-проєкт браузера персонажів всесвіту «Рік і Морті», побудований на React з використанням React Router та валідацією форм через Formik/Yup. Дані підтягуються з публічного [Rick and Morty API](https://rickandmortyapi.com/).

**🔗 Демо:** [посилання на GitHub Pages]
**📦 Репозиторій:** github.com/lamborghiniMiuraGt350/Rick-And-Morty-app

## Функціонал

- 📃 **Список персонажів** — посторінковий (або з нескінченною прокруткою) вивід персонажів з API
- 👤 **Детальна сторінка персонажа** — розширена інформація (статус, вид, походження, серії)
- 🔍 **Пошук і фільтри** — пошук за ім'ям, фільтрація за статусом/видом/статтю
- ✅ **Форми з валідацією** — реалізовані через Formik + Yup

## Що я відпрацював у цьому проєкті

- Клієнтський роутинг з динамічними маршрутами (сторінка окремого персонажа за id)
- Роботу із зовнішнім REST API: запити, обробка завантаження та помилок
- Валідацію форм на клієнті через Formik/Yup
- Композицію перевикористовуваних компонентів (картка персонажа, фільтри, пагінація)
